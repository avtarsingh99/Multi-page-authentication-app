This is Multi Page Authentication App – LibNest by Avtar

To run this project, do the following steps:

1. Open the project folder in any IDE (e.g VS Code/ Cursor)
2. Run the cmd "npm install" in the terminal
3. Run "npm run dev"
4. See the output on localhost in browser

This project code is uploaded on Github on the link: https://github.com/avtarsingh99/Multi-page-authentication-app
You can also see the deployed project on the link: https://multi-page-authentication-app.onrender.com/
